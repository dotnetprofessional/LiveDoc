# LiveDoc Viewer

<p className="intro">
Turn executable specifications into a live documentation site. The Viewer
organizes Vitest and xUnit results by project and behavior, updates while tests
run, and preserves the context needed to understand quality over time.
</p>

## What the Viewer Gives You

<div className="features-grid">

<div className="feature-card">
<div className="feature-icon">🔄</div>
<h3>Live Test Documentation</h3>
<p>Watch Features, Scenarios, Specifications, Rules, and steps update as your test suite executes.</p>
<p><a href="./learn/understanding-the-ui"><strong>Explore the interface →</strong></a></p>
</div>

<div className="feature-card">
<div className="feature-icon">📊</div>
<h3>Quality Signals</h3>
<p>See failures, rule violations, duration, and weighted line and branch coverage without confusing evidence with test status.</p>
<p><a href="./guides/code-coverage"><strong>Understand coverage →</strong></a></p>
</div>

<div className="feature-card">
<div className="feature-icon">🕘</div>
<h3>Runs You Can Revisit</h3>
<p>Browse full and partial run history, follow live updates, and share deep links to an exact project, run, folder, or test.</p>
<p><a href="./learn/understanding-the-ui"><strong>Learn about runs and links →</strong></a></p>
</div>

</div>
